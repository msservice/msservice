# ESO Mobile - Virtual Mobile Network Operator

Welcome to the ESO Mobile GitHub repository! This project is designed to create a Virtual Mobile Network Operator (VMNO) platform for managing user registrations, SIM card activations, mobile wallets, top-ups, airtime loans, calls, and messaging.

This repository includes the front-end web application that allows users to:
- Register for an account.
- Manage their mobile number, wallet, and account settings.
- Make calls and send messages.
- View recent transactions.

## Features

- **User Registration**: Users can sign up by providing their personal details such as name, email, and password.
- **SIM Card Registration**: Users can register for a SIM card within the dashboard.
- **Mobile Wallet Activation**: Allows users to activate their mobile wallet.
- **Top-up Balance**: Users can top up their account balance.
- **Loan Feature**: Allows users to borrow airtime, data, or loans.
- **Call and Message**: Users can make calls and send messages directly from their dashboard.
- **Recent Transactions**: Users can view a list of recent transactions, including payments and top-ups.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
- **API Integration**: Use of external APIs like [Twilio](https://www.twilio.com/) for messaging and call functionalities (example API integration provided).
- **Hosting**: GitHub Pages
